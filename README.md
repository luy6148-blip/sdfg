# 信息图形研究知识库

本仓库用于建立以案例观察为依据、可持续修订的信息图形设计知识体系。

## 目录

- [01-信息图形数据逻辑](01-信息图形数据逻辑/)：五种数据组织逻辑的概念、统计方法、视觉编码、数据/信息架构及视觉叙事架构；仅保存文本与指向案例库的链接，不保存图片。
- [02-信息图形类型案例](02-信息图形类型案例/)：混合型、文字/列表型、时间轴型信息图形的类型说明，后续每个案例单独保存分析文档与图像素材。

## 核心区分

**数据逻辑**回答“信息本质上怎样组织”；**表现类型**回答“设计如何编码并讲述信息”。二者是两个分类维度，不应一一对应。例如时间轴表现不一定只有编年数据，混合型也可能结合层级、地理、编目等逻辑。

## 证据与更新原则

1. 先记录案例来源、原图、背景，再做逐项分析；没有案例图时只撰写可检验的初始原则，标注“待案例验证”。
2. 所有案例统一检查 A数据逻辑、B统计图形与计算、C视觉编码、D数据/信息架构、E视觉叙事架构。
3. 区分观察事实、分析推断、待验证假设；引用具体案例时使用相对 Markdown 链接。
4. 新案例加入时，更新相应类型说明与数据逻辑说明中的“案例索引/规则修订记录”，保留修订原因与日期；更新在收到新案例和明确的任务时进行，不代表后台自动监控。
5. 不把数据可视化与信息图形绝对对立：信息图形可以包含统计图表，关键在解释、注释、符号及叙事组织。
